# AI use

The server may call xAI for research or, later, an image. The Android app never calls xAI.

A database query, a median and the legacy 64-dimensional hash are not AI embeddings. The hash remains a legacy fingerprint.

The provider account used for this check listed chat models and `grok-imagine-image`. It did not list an embedding model. Embeddings stay unavailable.

Users can report AI output from inside the app. A report is stored only when the database accepts it. A failed write is not described as saved.
